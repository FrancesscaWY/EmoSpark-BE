# EmoSpark-BE

EmoSpark 的后端仓库，用于承载儿童、家长与心理咨询师业务所需的 API、认证、情绪数据和咨询协作服务。

当前仓库仅完成项目初始化，暂未提交后端源代码、依赖配置或可运行服务；README 会随后端实现同步更新。

## 规划中的职责

- 用户、儿童档案与角色权限管理
- 情绪记录、沟通和成长数据接口
- 家长与心理咨询师的咨询协作接口
- 与 [EmoSpark-FE](https://github.com/FrancesscaWY/EmoSpark-FE) 的 API 契约
